# 支付集成执行与验证记录

日期：2026-11-05。

## 实现范围

- 新增 `000022_payment`，保存独立支付单、退款单、幂等事件及预支付标识/短时锁；旧订单豁免，新订单默认全额付款后进入确认履约。
- 本地模拟仅允许 `APP_ENV=local`、回环监听、显式启用和客户认证；模拟入口拒绝代理转发及他人订单。真实环境不注册模拟入口，不接受 MOCK 入账。
- 小程序区分开发者工具和手机，真机开发版使用联调 HTTPS 地址；模拟取消/失败/处理中不入账，真实失败不切换模拟。
- Go 短时凭据绑定支付单、客户、AppID、金额及有效期；云函数向 Go 取得权威金额与 OpenID，不能由客户端改写。
- HTTP 桥接使用双向服务签名、微信 RSA 响应验签和原始通知验签解密；明文通知只提供独立查单提示，不能直接驱动入账。
- 回调处理与金额更新、去重、审计同事务提交；定时恢复超时支付和退款，成功交易逐笔定期复核。已取消订单的真实迟到收款入账并提示人工退款。
- 后台支持交易记录、模拟标识、独立退款权限和可退余额预留；暂停新收款时保留在途交易处理。客户实付汇总排除模拟通道。

支付集成测试使用本次创建的 `fix_pro_payment_20261105_test`，不使用业务库保存测试交易。覆盖：

1. 12 个并发重复模拟成功仅入账一次。
2. 两个并发 70 分退款针对 100 分实付仅允许一个成功，剩余可退余额为 30 分。
3. 退款请求重放返回同一退款单，改写请求内容被拒绝，累计退款不能超额。
4. 跨客户访问和模拟付款、禁用通道、生产模拟入账、过期付款均被拒绝。
5. 商户号、金额、短时凭据和服务请求签名篡改被拒绝。
6. 预支付并发租约阻止同时下单，已保存预支付标识被复用。
7. 未付款订单不能生成工单；已付款和历史豁免订单可以确认，确认重试不重复生成。
8. 支付与取消/关单并发不丢失真实收款；取消后迟到付款保留取消状态并标记人工退款。
9. 迁移保留历史付款和豁免规则，新增订单要求付款，有支付事实时拒绝删除账务的回滚。
10. 停收款不关闭已有交易的查询/退款通道；HTTP 接口鉴权和回环限制生效。

## 本机运行

本机业务库从版本 21 升级至 22，无已有订单需要变更；新表创建成功。API 使用项目托管进程启动，监听 `127.0.0.1:8080`，本地模拟开启，真实支付关闭。健康检查返回 `UP`；模拟付款入口无登录返回 401；真实回调入口未启用返回 404。

启动时专用 Go 缓存缺少依赖，下载遇到网络超时；改用已有模块缓存后构建并恢复服务。启动脚本现在允许外部指定 `GOMODCACHE`，不需要重复下载已缓存模块。

# ADR-001：采用 Java 模块化单体

- 状态：已接受
- 日期：2026-08-01

## 决策

后端使用 Java LTS + Spring Boot 3.5，以单一 API 应用和独立 Worker 部署。代码按领域模块隔离，通过本地事务和 Outbox 保证一致性；V1 不采用微服务。

## 原因

- 初期团队小，开发和运维复杂度必须受控；
- 订单、报价、支付、库存与工单有强事务关系；
- 模块边界和 Outbox 可以支持后续渐进拆分。

## 后果

- 模块之间禁止直接访问对方 Mapper；
- 核心表由唯一模块负责写入；
- 媒体、通知、报表等异步副作用通过 Outbox 执行。

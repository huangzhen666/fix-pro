一、业务调整：三大赛道（放弃装修公司，聚焦三类客户）
 
1）零售业主（散户，广告投放核心）
 
定位：现金流引擎、品牌基础、小程序广告主要获客来源
业务：家电清洗（引流）、家电维修、家庭水电维修、漏水检测、灯具卫浴更换、旧房局部水电改造
获客：抖音同城、朋友圈广告、小区推广、业主群、老客转介绍
特点：客单价中等、毛利高、现款结算、复购稳定；缺点订单零散、淡旺季明显。
 
2）物业合作（稳定保底业务）
 
两种合作模式分开布局
①小区公共设施维保（楼道照明、水泵、公共水管）：月度/年度包干维保合同；
②业主增值特约维修：物业推荐住户上门服务，佣金分成。
结算要点：优先约定季度结算，设置账期上限，逾期暂停服务；全部工单小程序留痕，方便对账追责。
 
3）政企、工厂、商铺（高客单、平滑淡旺季）
 
客户：政府单位、学校、医院、厂房、门店、写字楼
业务：中央空调清洗维护、厂房电路检修、给排水维保、定期安全巡检、批量家电维保
优势：大单、持续性强，对冲家庭业务淡季；
注意：政企普遍走对公对公，账期1–3个月，必须单独核算资金成本，不允许无限制垫资。
 
三条业务客户分工建议
 
- 广告团队：主攻散户零售业主；
- 商务专员：专门对接物业、工厂、政企投标/洽谈维保年单；
风险隔离：散户尽量全款；物业适度短账期；政企严格控制授信总额。
 
二、行业有没有前途？行业上限到底有多高？
 
客观结论
 
✅赛道长期存在（刚需赛道，不会消失），但是【个人师傅体力收入上限很低；标准化公司模式上限很高】
 
第一层上限（个人单打独斗）
 
单纯靠自己上门干活：天花板明显，受时间、体力限制，属于卖时间赚钱。旺季忙碌、淡季冷清，年收入存在明显瓶颈。大量游击队停留在这个层级。
 
第二层上限（组建3–8人本地团队，县城标准模式，你的起步目标）
 
靠广告获客+系统派单，团队化运营。
收入区间（县城成熟运营）：年净利润 25万～60万
盈利逻辑：不靠老板亲自干活，赚管理差价、转化差价、长期维保合同收益。
 
第三层上限（成熟扩张，长期目标）
 
1. 拿下多家物业长期维保、政企年度维保框架；
2. 推出家庭年度维保会员卡锁定居民持续消费；
3. 拓展商用清洗、中央空调维保、厂房水电整改；
4. 后期开设社区服务站点，发展合作班组；
年净利润可冲击 80万–150万。
 
行业短板（提前规避）
 
1. 入门门槛低，大量低价游击队内卷，必须走标准化、品牌化、透明报价路线，不打价格战；
2. 淡旺季分化：夏季空调旺季、年末清洗旺季；春秋淡季，依靠政企/物业常年维保平滑收入；
3. 安全风险高（高空、水电施工），全员配齐意外险、高空作业保险；
4. 最大坑：盲目垫资接政企、物业长账期业务，现金流断裂。
 
一句话总结：不想一辈子上门干活，就不能只做维修，要做成本地维保服务平台，靠系统、团队、长期维保合约突破收入天花板。

# 灵狸护家小程序首页视觉优化方案

**已选方向：** 深蓝 · 清爽服务。  
**实施计划：** [PLAN-014｜客户小程序深蓝视觉与首页优化](./plans/PLAN-014-客户小程序深蓝视觉与首页优化.md)。

## 目标与边界

将首页调整为干净、可靠、容易找服务的家庭维修入口。现阶段先确定视觉和信息布局，下一步再落实页面代码。

延续已确定的交互：顶部品牌栏单行且不超过 70px，搜索滚动吸顶，服务可加入购物车或立即下单，服务城市仅汉川市。品牌沿用当前的“灵狸护家”和现有 logo。

## 当前观感问题

1. 大面积米黄底、暖色渐变、棕色文字和棕色按钮叠加，整个页面都在强调品牌色，缺少轻重关系。
2. 彩色 emoji、复杂 logo、服务图片和购物车表情混用，图形语言不统一。
3. 标题、服务名、价格普遍加到 700–800 字重，再叠加阴影与圆角，页面显得厚重。
4. 首页同时展示品牌、搜索、分类、承诺说明、推荐服务、咨询和浮动购物车，第一屏的服务入口不够突出。
5. 服务卡片图片缺少统一的选图标准；当前推荐只是取目录前四项，不能自然表达用户最常用的服务。
6. “后台发布服务后，将在这里自动展示”等开发说明仍在首页，咨询按钮目前只打开说明弹窗，和用户预期不一致。

以上是基于现有页面代码与会话截图的设计判断，并非已完成的真机视觉验收。

## 推荐方向：白底、深蓝操作色、少量品牌橙

### 配色角色

| 角色 | 建议色值 | 用法 |
| --- | --- | --- |
| 页面底色 | `#F5F7FA` | 页面留白和模块间隔，替换米黄色铺底 |
| 内容表面 | `#FFFFFF` | 顶部、分类区、服务卡片、底部导航 |
| 主文字 | `#1F2937` | 服务名称与主要信息，替换大面积棕字 |
| 次要文字 | `#5F6F84` | 单位、辅助说明和次要入口 |
| 主要操作 | `#204F76` | 主要按钮、选中导航、统一图标 |
| 轻强调背景 | `#EDF3F8` | 分类图标底板、浅色次级按钮 |
| 品牌点缀 | `#E77932` | logo 延伸的小标识，避免作为大面积背景 |
| 价格文字 | `#B94B20` | 服务价格，避免满屏亮红 |
| 分隔线 | `#E8EDF2` | 吸顶搜索下沿、列表边界 |

深蓝用于说明“哪里可以操作”，橙色用于保留品牌识别，白色与浅灰负责大部分页面面积。每个屏幕尽量只有一个高强调行动按钮。颜色只是设计方向，不代表某种颜色天然“高级”。

普通正文与背景的对比度以至少 4.5:1 为目标；橙色点缀不直接搭配细小白字。参考：[W3C 文本对比度要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)。

### 备选方向：轻橙品牌

若希望强化现有橙色 logo，可采用白色底和炭灰文字，仅让主要按钮、价格和少量选中图标用深橙。服务卡片使用双列，整体更亲切。避免恢复米黄铺底、橙色渐变和棕色长段文字。优先推荐深蓝方案，备选用于比较品牌亲和力与操作辨识度。

## 各区域怎么改

| 区域 | 具体改法 | 用户看到的变化 |
| --- | --- | --- |
| 顶部品牌栏 | 高度 56–64px，硬上限 70px；logo 缩至 32–36px；一行放品牌名和“汉川市”；不再单独放口号 | 品牌清晰，首屏更快看到服务 |
| 搜索区 | 白色吸顶底板；搜索框高 44px；浅灰底、深灰搜索图标；取消厚阴影；提示“搜索服务，如漏水检测” | 滚动时仍能搜索，控件与内容层次分明 |
| 服务分类 | 保持真实业务分类与全部服务入口；首排至多五项；同一套线性图标，统一笔画；图标底板用很浅的蓝灰；名称保持单行 | 分类像完整的一套组件，减少零散感 |
| 服务保障 | 取消独立大卡片和三段小字；收成一行“透明报价 · 过程留证 · 售后可查”，依据真实服务能力展示 | 节省首屏空间，强化可信信息 |
| 推荐服务 | 推荐方案改为单列横向卡片：左图、右侧服务名与一行说明，价格独立展示；首批约 3–4 项，不硬塞满一屏 | 维修类长名称更容易读，选择更清楚 |
| 服务图片 | 统一 4:3 或方形裁切；使用清晰的实际服务场景或服务对象；不要图片里再塞大字、低清拼图或重复 logo | 消除最明显的廉价感来源之一 |
| 咨询入口 | 用普通白卡或列表行，降低颜色权重；只有接通真实客服时才写“联系客服”；当前阶段可写“选服务有疑问？”并提供有用说明 | 按钮文案与实际动作一致 |
| 购物车 | 改为统一线性图标配数量角标；采用白底轻描边浮动按钮，或轻量底部入口；位置避开内容与系统底栏 | 可找到购物车，也不会抢过服务内容 |
| 底部导航 | 白底；未选中灰色，选中深蓝；图标与分类同一套 | 页面整体统一 |
| 空态与错误 | 空态改为“服务正在准备中，请稍后再来看看”；错误提示使用面向用户的语言，不展示后台、SKU、硬编码等说明 | 页面像正式产品，而不是开发演示 |

## 推荐的内容顺序

1. 原生导航。
2. 紧凑品牌栏：logo、灵狸护家、汉川市。
3. 可吸顶搜索。
4. 真实服务分类。
5. 一行服务保障。
6. 常用服务卡片。
7. 服务选择帮助。
8. 底部导航；购物车以轻量入口常驻。

首屏目标是在常见手机上看见完整分类区和至少一部分服务内容；实际可见数量随屏幕高度、系统字号变化，不硬性要求所有设备完全相同。

## 字体和间距

- 品牌名 17px、模块标题 17–18px、服务名称 15–16px、价格 18–20px、辅助文字 12–13px。
- 主要标题和按钮用中等加粗，正文常规字重，避免全页 800 字重。
- 左右边距统一为 16px；卡片间距 12px；模块间距 20–24px。
- 卡片圆角 12–16px；搜索框和主按钮可用胶囊形；不要所有元素都做很大的圆角。
- 卡片以白色表面和间距区分，阴影最多保留一套很轻的样式。
- 以实际手机像素作为设计目标，落实到 rpx 时要处理屏幕宽度差异，尤其确保品牌栏不会超过 70px。

## 推荐内容的真实性

“常用服务”“热门推荐”应有相应选择依据。当前仅按服务目录取前四项时，可暂用“为你推荐”或“服务推荐”，避免虚构热门、销量、评价、原价折扣和服务保障。价格、单位和服务范围以实际发布内容为准。示意图不提供示例成交价。

## 实施顺序

**第一步：统一视觉基础。** 明确背景、文字、操作色、品牌点缀色；统一字体、间距和图标，先解决整体色调与零散感。

**第二步：重排首页。** 落实紧凑品牌栏、吸顶搜索、分类和简化保障条；完成推荐服务卡片与购物车入口。

**第三步：补齐素材与真实内容。** 整理服务图片、修正空态与咨询入口，再把相同颜色规则同步到搜索、购物车、结算页面。

## 后续落地检查点

- 品牌栏在目标设备上不超过 70px，文字不挤压换行。
- 搜索在页面滚动时始终可触达，吸顶时不遮挡原生导航和分类内容。
- 关键文字清楚，系统大字体下仍能辨认、操作。
- 图标风格一致，首屏没有开发术语、无依据的促销和过度承诺。
- 购物车、加入购物车、立即下单、地址选择维持已确定的交互。

这份方案阶段不改动首页业务代码，也未运行功能测试。

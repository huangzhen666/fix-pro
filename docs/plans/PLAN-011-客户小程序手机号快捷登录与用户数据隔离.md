## 1. 交付目标

完成以下用户链路：

```text
游客浏览服务
→ 主动点击手机号快捷登录并授权
→ 未注册手机号自动建档，已注册手机号复用账户
→ 登录后只访问本客户的购物车、地址、订单和工单
→ 点击“我的”头像编辑头像、昵称
→ 保存后立即更新展示，再次登录和跨设备使用恢复最新资料
→ 会话失效时清理个人缓存，重新授权恢复账户
```

完成条件：

- 同一组织、同一手机号只有一个客户账户；不同手机号业务数据相互隔离。
- 同一手机号在不同微信环境登录复用账户，OpenID 单独不能登录手机号账户。
- 手机号、会话、微信环境和资料媒体遵守 SPEC-011 的存储、验证及权限规则。
- 全部客户私有接口采用真实客户会话，包括详情、写操作、媒体、验收、评价和幂等结果。
- 头像昵称编辑和后台平台注册用户及使用情况查询属于本期交付，不延期至后续阶段。
- 上线前一次性清空客户测试数据及关联私有媒体，保留服务目录、组织、后台账号和师傅档案。
- SPEC-011 第 12 节验收项全部完成，并记录自动化与真机验证证据。

实施结果见 [PLAN-011 验收记录](../test-reports/PLAN-011-e2e.md)，记录实现、自动化和本地初始化证据；真实微信验收及发布尚未完成。本期不提供客户退出登录或切换账号入口、接口。密码登录、自建短信登录、账号改号、不同手机号数据合并、后台账号状态操作和营销分析另行规划。

## 3. 实施原则与依赖

1. 以 SPEC-011 V1.5 为契约，接口和页面行为保持一致，发现歧义先在实现记录中明确决定。
2. 不改写已执行数据库迁移；新结构迁移与一次性业务数据清理分别交付。
3. 外部微信调用在数据库建档事务之前完成，禁止持有事务等待微信网络请求。
4. 手机号账户唯一性由数据库兜底，OpenID 只记录环境，不替代手机号授权。
5. 身份来自客户会话，归属校验覆盖所有私有资源的读写和引用。
6. 沿用现有模块化单体、HTTP 响应、媒体和会话机制，按功能组织新增代码。
7. 自动化测试在独立测试数据库中执行，不对开发业务数据库反复运行清空测试。
8. 验收记录区分自动化通过、开发者工具通过、真机通过和待外部依赖验证，不把测试桩结果当作真实微信验收。

### 3.1 外部依赖

在 A0 记录以下项目的可用状态，凭据仅通过本机环境或部署密钥注入：

- 客户小程序真实 AppID 与 AppSecret；
- 已认证非个人主体、手机号能力资格、可用额度；
- 用户协议、隐私政策的实际页面及手机号、头像昵称收集说明；
- 请求、上传、下载 HTTPS 域名和基础库能力兼容；
- 两个不同真实手机号、两个微信环境，用于不同账户隔离和同账户跨环境验证；
- 手机号加密密钥、HMAC 检索密钥及安全保存位置。

依赖未就绪时，继续完成数据库、网关测试桩、认证和前端实现；真实手机号授权与上线验收保持待完成，不增加绕过认证的运行接口。

## 6. A1｜数据库、初始化清理与夹具

### A1-1｜新增结构迁移

拟新增：

```text
apps/server-go/db/migrations/000016_customer_auth_profile.up.sql
apps/server-go/db/migrations/000016_customer_auth_profile.down.sql
```

- `customer` 增加状态、最近登录、最近活跃时间、手机号验证时间、头像媒体引用，沿用显示名和版本字段。
- 增加组织及注册时间、组织及活跃时间索引，复用客户订单索引支持用户汇总。
- 建立 `(org_id, mobile_hash)` 唯一约束，不通过部分索引释放禁用、软删除账户的号码。
- 新建 `customer_wechat_identity`，唯一键为 `(org_id, customer_id, appid, openid)`；允许手机号客户与微信环境多对多关联。
- 新建 `customer_session`，记录客户、组织、AppID、OpenID、Token 哈希、时间和撤销状态；建立 Token 哈希唯一索引及客户会话索引。
- 为客户建立所需复合唯一键，身份与会话使用组合外键保证组织一致。
- 增加 `customer.view` 菜单权限及 `/customers` 路径，赋予现有内置租户管理员；同步新组织的内置权限初始化逻辑，不给自定义角色隐式赋权。
- 头像引用约束与媒体删除保护协同设计，避免先删媒体造成失效引用。

### A1-2｜处理旧种子与必填约束的部署顺序

旧种子没有手机号，不能在清理前直接把手机号列改为 NOT NULL，导致整个结构迁移失败。

- 结构迁移可先添加手机号必填的 `CHECK ... NOT VALID`，约束新写入，但不扫描旧种子；账户服务同时要求创建时加密及检索字段均存在。
- 上线前一次性清空测试记录后，验证该约束并完成手机号列 NOT NULL 收口。
- 明确记录最终结构要求，初始化收口失败不得开放真实客户写入。
- 新建数据库同样采用“全部结构迁移 → 一次性初始化清理及约束验证 → 启动客户业务”的流程，消除旧基线迁移产生的演示种子。
- 日常重新执行 `migrate` 或重启服务不能重新插入演示账户，也不能再次清空客户数据。

### A1-3｜一次性初始化工具

建议新增 `apps/server-go/cmd/init-customer-auth`，独立于 `cmd/migrate` 和服务启动路径。

- 默认只输出清理范围、表级计数和媒体对象清单；显式执行模式才清空数据。
- 在独立测试数据库先演练，清理时暂停客户及相关工单写入，确认目标数据库及媒体根目录。
- 从客户、订单、工单的实际依赖图确定删除顺序，包括完工、审核、客服确认及循环外键关系；需要先解除循环引用时在同一事务处理。
- 清理客户地址、购物车、订单、工单及相关记录、客户会话、身份、客户幂等记录。
- 对 `outbox_event`、`audit_log` 等共享表只清理指向本次测试业务的记录，不整表删除；按实际 schema 核对引用方式。
- 保留组织、管理员及权限、师傅档案及技能、服务目录和公开商品媒体。
- 数据库提交前保存待清理私有媒体对象清单；提交后删除文件或对象，失败可按清单重试，不重新执行全库业务删除。
- 清理测试客户头像、故障和工单证据前排除保留资源的引用；不删除整个媒体目录。
- 记录一次性初始化完成状态，完成后拒绝再次整批清空；单独允许未完成媒体对象的重试。
- 执行约束验证、表级计数及孤立引用检查，不依赖客户序列重置为 1。

下线测试业务是本期初始化行为，不设计旧数据认领或迁移到真实客户的逻辑。

### A1-4｜测试夹具

- 创建测试客户时使用受控手机号加密/HMAC 与组织配置；不添加任意 ID 的生产登录接口。
- 用微信网关测试桩模拟手机号和 OpenID 返回，走正常账户服务得到测试会话。
- 测试记录按测试批次标识定向清理，避免复用初始化命令删除正常测试进度。

退出条件：迁移、必填约束收口、清理重复执行保护和媒体重试在独立数据库演练通过。

## 7. A2｜微信网关与配置

建议新增 `internal/platform/wechat`，暴露可替换的微信网关接口。

- 分别实现手机号专用 Code 兑换、登录 Code 换取 OpenID，不用 `session_key` 解密手机号。
- 实现微信服务端 access_token 缓存、提前到期判断和并发刷新；失效时受控刷新，不能无限重放单次手机号 Code。
- 校验平台返回结果、AppID 水印、国家区号、手机号格式，规范化为 `+86` 加 11 位号码。
- 外部调用配置明确超时，按规格映射无资格、无额度、失效 Code、网络异常等错误。
- 配置加入 AppID、AppSecret、默认组织、168 小时会话期限和两套独立手机号密钥。
- 手机号使用带认证加密和 HMAC-SHA-256，采用明确编码、随机 nonce 和密钥格式验证。
- 生产缺少必要配置时启动失败；本地其他业务可运行，手机号登录返回配置不可用。
- HTTP 及诊断日志不得打印凭据查询串、完整手机号、Code、上游 access_token 或密钥。

验证覆盖：正常结果、失效与混用 Code、非本 AppID、异常号码、限流、缓存并发、上游超时及配置错误。真实网关验证依赖已开通的微信能力。

## 8. A3｜客户认证与会话

建议新增 `internal/customer` 的认证 Handler/Service，以及 `internal/platform/auth/customer_session.go`。

- 实现 `POST /mini/auth/phone/login`，先完成两类微信验证，再在事务中查找或创建手机号客户、记录环境、创建会话并更新登录时间。
- 用手机号唯一约束处理并发，冲突后重新读取可用客户；失败事务不留下客户、绑定或会话半成品。
- 禁用、软删除客户返回不可用，不能绕过唯一身份另建同号账户。
- 随机 Token 不少于 32 字节，只存 SHA-256 哈希，会话期限按配置确定。
- 实现 `POST /mini/auth/session/verify`：现有 Token 加新 `loginCode` 验证相同环境，返回原期限，不签发或续期 Token。
- 实现 me，统一返回包括最新头像昵称和版本的客户响应；保留服务端撤销能力，用于账号不可用等会话失效处理，不新增客户端退出接口。
- 中间件验证组织、客户状态、过期及撤销，写入客户 Principal。
- 替换 `auth.Customer` 的演示路径；所有环境拒绝 `local-customer-1`，师傅 Token 和管理员 Cookie 不能作为客户会话。
- 实现基础登录限流和受控错误映射。

验证：同号跨微信环境复用、不同号码独立会话隔离、并发建档、失败无残留、会话过期与撤销、环境变化及账号禁用，不通过产品切换账号入口进行测试。

## 9. A4｜全部客户资源隔离

- 按 A0 路由矩阵逐项改造 `internal/cart`、`internal/address`、`internal/order`、`internal/fulfillment` 和 `internal/media`。
- 列表、详情、更新、删除和引用同时校验 `org_id + customer_id`，子资源检查父资源。
- 订单创建及幂等记录使用会话身份，禁止客户端指定客户、组织或角色。
- 工单通过所属订单验证客户，覆盖工单详情、时间线、验收、评价及证据读取。
- 修复 `SubmitRating`：归属、完工提交及可评价状态与写入在事务或条件 SQL 内完成；越权不留下评价记录。
- 保留已有版本和业务状态约束；不重构订单、派单及验收状态机。
- 故障媒体读写和引用按所有者校验，完工证据只展示当前客户且 `customer_visible` 的记录。
- 公开媒体仅允许已发布服务明确引用的图片，头像及私有证据不能经公开路由读取。
- 同一幂等 Key 在两个客户账户下各自生效。

退出条件：路由矩阵没有未检查的私有接口，跨客户和跨组织读写失败且数据库状态未改变。

## 10. A5｜个人资料与头像后端

- 实现当前客户资料 GET/PUT，不接受目标客户 ID，白名单只允许昵称、头像引用和资料版本。
- 昵称去除首尾空白后为 1～32 个 Unicode 字符，拒绝空值、控制字符及换行。
- 根据平台要求接入头像昵称检测，确定服务器必要检测与前端检测结果的处理，不仅依赖普通输入事件。
- 头像专用上传处理 JPEG、PNG、WebP，5 MB 上限，同时限制请求体、检测实际内容并验证可解码。
- 检查当前图片解码依赖是否覆盖 WebP；需要增加解码库时纳入正常依赖配置，不改变故障证据接口现有限制。
- 上传用途固定为 `CUSTOMER_AVATAR`；返回字段按契约为 `mediaId`，与现有媒体接口的 `id` 字段显式适配。
- 资料保存校验媒体所有者、组织、用途及状态，用 `version` 条件更新头像昵称并递增版本；冲突返回 409。
- 头像采用受保护下载地址，不返回临时路径和任意客户端 URL。
- 当前头像被引用时禁止直接删除；替换成功后回收无引用旧头像，未关联上传按保留期清理。
- 媒体回收处理并发引用与删除，不能在回收检查后又允许已被删对象绑定。
- 资料修改保持会话有效，不变更手机号或现有订单联系人快照。

退出条件：资料正常保存、类型和大小校验、越权引用、版本冲突、上传后提交失败及旧头像回收均可验证。

## 11. A6｜小程序登录与缓存隔离

建议新增 `services/auth.ts`、统一客户会话模块及 `pages/login/index`，调整 `app.ts`、`app.json` 和 `services/request.ts`。

- 登录页提供单一手机号快捷登录按钮、协议链接和“未注册将自动创建账号”说明，不设置协议复选框。通过 `onNeedPrivacyAuthorization` 展示隐私弹窗，原生同意按钮回调后 resolve 本次请求，自动继续手机号授权；已同意隐私时不重复弹窗。拒绝或取消授权保持游客状态。
- 用户点击原生授权获得 `phoneCode`，独立调用 `wx.login` 获得 `loginCode`，按契约请求登录。
- 取消、拒绝、额度不足和网络错误有明确状态，保留游客浏览；不增加手填手机号直接登录路径。

- 登录成功恢复页面及合理草稿，订单、验收、评价写操作由用户确认，不自动重放。
- 冷启动有 Token 时调用环境校验；校验通过前不发个人请求，不显示旧资料。
- 网络暂不可用保留可恢复状态并阻止个人数据展示；确认失效或环境变化时清理会话并重新引导登录。
- 请求、上传、下载统一处理 401，合并并发登录与环境校验任务。
- 订单已读状态缓存按组织和客户命名，清理原共享键及旧演示 Token。
- 为会话变化维护身份代次；响应回写前验证客户和代次，阻止旧请求污染新页面。
- 清理 `profile/index.ts` 等模块级失效身份数据；删除计划中的主动退出状态标记和切换账号流程，有效登录态正常恢复，失效后重新授权。
- “我的”、资料编辑页和登录有效态不提供退出、切换账号或改号按钮；管理员及师傅现有功能沿用各自规格。
- 同步清理私有媒体临时缓存，不能从头像本地文件展示上一客户资料。

退出条件：公开页面游客可用，全部个人入口受保护，回跳、环境恢复和异步竞争不串账户。

## 12. A7｜点击头像编辑个人资料

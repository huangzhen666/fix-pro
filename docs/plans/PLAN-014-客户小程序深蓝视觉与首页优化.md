# PLAN-014｜客户小程序深蓝视觉与首页优化实施计划

**状态：** 实现及本机检查完成；完整模拟器操作与 iOS/Android 真机验收待完成  
**版本：** V1.0  
**日期：** 2026-10-28  
**设计依据：** [首页视觉优化方案](../首页视觉优化方案.md)，采用用户确认的“深蓝 · 清爽服务”方向  
**适用工程：** `apps/wechat-mini`  
**执行顺序：** 基线记录 → 视觉基础与图标 → 首页改造 → 关联页面统一 → 交互与真机验收

> 本轮实施结果与证据见 [验收记录](../test-reports/PLAN-014-home-visual.md)。编号 013 已用于维修 SKU 结构化详情规格，本计划使用 014，避免与该需求混淆。

## 1. 交付目标

把客户小程序首页调整为清晰、可靠、容易找服务的家庭维修入口，并统一浏览与下单链路的视觉。

用户进入首页后的主路径：

```text
确认品牌与服务城市
→ 搜索或选择分类
→ 查看服务说明与真实价格
→ 加入购物车，或立即下单
→ 选择汉川市地址与预约时间
→ 确认并提交订单
```

完成时应达到：

- 首页使用白色内容区、浅灰背景、深蓝操作色和少量橙色点缀，取消大面积米黄与棕色渐变。
- 品牌栏单行，标准高度 60px，任何目标手机宽度下均不超过 70px。
- 搜索框随滚动吸顶，始终可触达，且不覆盖原生导航。
- 分类采用统一线性图标，服务推荐采用单列横向卡片。
- 搜索、服务列表/详情、购物车、结算页面与首页使用相同颜色和组件规则。
- 现有登录、加购、独立立即下单、购物车选择及删除、地址和预约交互维持正确。
- 有页面截图、关键交互结果和实际设备信息；未验证的真机项目不得写为通过。

## 2. 范围与实施边界

### 2.1 本期必做

1. 客户小程序共享颜色、文字、间距、圆角与图标基础。
2. 首页品牌栏、吸顶搜索、分类、保障条、推荐服务、帮助入口和购物车入口。
3. 服务列表、搜索、服务详情、购物车、结算及结果页的视觉统一。
4. 登录、个人资料、地址、订单和客户小程序内工作台等共享样式受影响页面的主题兼容检查与必要颜色替换。
5. 相关加载、失败、空态和面向用户的文案整理。
6. 开发者工具与真机验收记录。

### 2.2 本期不扩展

- 不新增后台、师傅小程序、数据库迁移或后端接口。
- 不更改价格计算、订单状态、认证权限、缓存键和资源隔离规则。
- 不新增优惠券、虚构热度、销量、评价、AI 推荐、在线客服平台或未实现的售后能力。
- 不切换页面渲染框架，不新增大型 UI 组件库，不制作独立暗色主题。
- 不以视觉改造替代 [SPEC-013](../specs/SPEC-013-通用服务SKU管理与结构化图文详情.md) 的服务内容和计价边界建设。

### 2.3 已确认的交互约束

| 场景 | 必须保留的行为 |
| --- | --- |
| 首页品牌 | 沿用“灵狸护家”和现有 logo；顶部内容只占一行 |
| 搜索 | 点击进入现有搜索页，关键词查询继续使用真实服务目录；首页滚动时入口吸顶 |
| 加入购物车 | 仅加购、反馈成功并更新数量；不跳转结算 |
| 立即下单 | 使用当前服务与选定数量独立结算，不合并或清空已有购物车 |
| 购物车 | 查看详情、选择项目、修改数量、左滑显示删除、删除确认、勾选结算 |
| 地址 | 城市下拉只有“汉川市”，保存时传选中值；具体地址支持微信选址与手填 |
| 身份 | 游客可以浏览；需要身份的操作按既有登录流程回跳 |

## 4. 冻结视觉规范

### 4.1 颜色角色

| 变量建议名 | 色值 | 使用位置 |
| --- | --- | --- |
| `--color-page` | `#F5F7FA` | 页面底色与模块间隔 |
| `--color-surface` | `#FFFFFF` | 品牌栏、分类区、内容卡和导航 |
| `--color-text` | `#1F2937` | 标题、正文、主要服务信息 |
| `--color-text-secondary` | `#5F6F84` | 单位、辅助说明、次级入口 |
| `--color-primary` | `#204F76` | 主按钮、选中状态和主要图标 |
| `--color-primary-soft` | `#EDF3F8` | 图标底板、次级操作背景 |
| `--color-brand-accent` | `#E77932` | 小面积品牌点缀，不铺满卡片 |
| `--color-price` | `#B94B20` | 价格 |
| `--color-border` | `#E8EDF2` | 分隔线与轻描边 |
| `--color-danger` | `#C83E3E` | 删除、错误等语义明确的操作 |

原则：正文不通篇使用棕色；大面积取消渐变；相同操作使用相同颜色；删除与价格通过位置、标签、形状区分。普通正文与背景对比度目标至少 4.5:1，实际前景/背景组合在实施验收时核对。依据见原视觉方案中的 W3C 引用。

### 4.2 字体、尺寸与间距

- 品牌名与模块标题：17–18px，中等加粗；服务名：15–16px；正文与操作：14–16px；辅助文字：12–13px；价格：18–20px。
- 正文常规字重，主标题 600 左右，不再大面积使用 800。
- 统一左右边距 16px、卡片间距 12px、模块间距 20–24px。
- 卡片圆角 14px，图标底板 12–14px；搜索框保留胶囊形。
- 品牌栏固定设计高度 60px，logo 36px；搜索框 44px，外层底板约 56–60px。
- 以实际 CSS px 定义品牌栏高度和控件最低触达尺寸；可伸缩布局使用 rpx。禁止把“128rpx”直接当作所有设备上的“64px”。
- 普通文字不固定容器高度；较大字号时服务名允许两行，说明一行省略，价格与单位不互相挤压。
- 卡片主要靠表面和间距区分，取消厚阴影；吸顶底板只使用细分隔线或极轻阴影。
- 原生导航沿用微信提供的系统区域，品牌栏 70px 上限不包含原生导航与状态栏。

### 4.3 图标与素材

- 页面图标统一为本地线性 SVG，同一尺寸和笔画；原生 TabBar 用同源导出的本地 PNG。
- 不为图标引入在线字体、远程脚本或整套大型运行库；补充素材时记录来源与许可证。
- 类别图标优先按真实分类 ID 配置，已知名称可用于兼容映射，未知类别使用通用图标；禁止按数组下标循环分配图标。
- 现有品牌 logo 保留比例，不拉伸；资源体积优化只生成显示所需尺寸，保留原始品牌源文件。
- 首页服务图片统一为方形缩略图、`aspectFill`；图片失败时使用统一浅色底和本地图标，不出现裂图。
- 会话示意中的“配图示意”和“查看服务”不是线上价格模板。正式卡片必须展示接口返回的价格及单位，不提交占位价格、假案例、假评价。
